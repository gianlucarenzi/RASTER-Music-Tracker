# RITMO 2.3 – the new name, a user manual in PDF, a window that fits your screen

**RASTER Music Tracker 2.x is now called RITMO** (*RITMO Is a Tracker for Music On Atari*): the same tracker, the same songs and the same sound, renamed so that it can never be confused with the original RMT, and free from the Windows-only MFC code. It is a fork of the RMT project by Peter Dell (JAC!), to whom I am infinitely grateful, built on the work of Radek Štěrba (R.I.P.) and VinsCool.

## New: the RITMO User Manual (PDF)

**[Download the user manual (PDF, 84 pages)](https://github.com/gianlucarenzi/RITMO-Music-Tracker/releases/download/v2.3/Ritmo-User-Manual.pdf)** – it explains the program from the first song to the export formats and the scripting, with **screenshots of every part of the window, of all the menus and of the dialogs**, a tutorial, the complete reference of the keys and the fields, the tracker drivers, MIDI input, the Pokey explorer and the module file format. It is also in the repository (`doc/manual/`), written in LaTeX.

| All | `Ritmo-User-Manual.pdf` | the manual |

Everything the program needs is inside each package.

## What changed

- **New name, icon and logo.** The program is `ritmo` (`Ritmo.exe`), with a new icon (the 16×16 size is drawn by hand) in the window, in the About window and in the packages. The About lists the people of RMT and of RITMO.
- **Your settings come with you.** The configuration is `ritmo.conf` (registry key, plist); the settings of RMT (`rmt.conf`, `rmt.ini`) are taken over at the first start. Songs, instruments and tracks are the same files, with the same `.rmt` and `.rmw` extensions.
- **The window fits the screen.** It opens at 1366×768 (a small laptop: a mono song is shown whole, with the POKEY registers), reduced to what the screen has; the first start chooses the interface size (100, 200 or 300 %) from the size of the screen; the size and the position are remembered; `--scale=N` sets the interface size of one session.
- **Qt only.** The MFC (Windows-only) code is removed: the Visual Studio project, the MFC windows and dialogs, the DLL-based sound. The 6502 and the POKEY are always the built-in emulations, on every platform; the exported WAV files are byte for byte the same as before.
- **More of the 6502.** The built-in 6502 knows the stable undocumented opcodes (LAX, SAX, SLO, RLA, SRE, RRA, DCP, ISC, ANC, ALR, ARR, AXS, SBC $EB, the NOPs), so the RMT drivers and players that use them run.
- **From RMT 1.36:** scripting from the command line (`ritmo /SCRIPT:build.rmtscript`), the Pokey explorer, the menus and the Windows standard keys, the stereo and SAP/XEX fixes, the export guard, and more.
- **Drivers:** when a song that uses the AUTOFILTER is opened with the Patch16 driver, the program asks whether to play it with the RMT 1.28 Unpatched driver; the sound routines of the 6502 are now also available as sources for ca65.
- **Audio:** diagnostics of the sound output at start and for underruns (`RMT_AUDIO_DEBUG`), and `RMT_AUDIO_BUFFER_MS` for the size of the buffer.
- **Releases:** the Windows build comes with an installer; the repository is now **RITMO-Music-Tracker** (the old address redirects).

The whole list is in the [change history](https://github.com/gianlucarenzi/RITMO-Music-Tracker/blob/master/doc/rmt_changes.md). As always, **please tell me how it works for you** by opening an [issue](https://github.com/gianlucarenzi/RITMO-Music-Tracker/issues): the Windows and macOS packages are built automatically and have seen little use on real machines.
