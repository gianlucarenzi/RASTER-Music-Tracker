# RASTER Music Tracker 2.2 – sharp on Qt6

**RMT 2.2 fixes the blurred text and icons of the Qt6 version on screens with a fractional scale.**

The tracker itself is the same as in [2.1](https://github.com/gianlucarenzi/RASTER-Music-Tracker/releases/tag/v2.1): same songs, instruments and settings. As always, **please tell me how it works for you** by opening an [issue](https://github.com/gianlucarenzi/RASTER-Music-Tracker/issues).

## Downloads

| System | Package | How to start it |
|--------|---------|-----------------|
| Linux x86_64 (Debian 11, Ubuntu 20.04 and newer) | `RMT-Linux-x86_64.AppImage` | `chmod +x RMT-Linux-x86_64.AppImage`, then run it (needs `libfuse2`; without it add `--appimage-extract-and-run`) |
| Windows 64 bit | `RMT-Windows-x64.zip` | unzip it anywhere and run `Rmt.exe`; it is not signed, so Windows may ask to confirm |
| macOS 12 or later, Apple Silicon | `RMT-macOS-arm64.dmg` | drag `RMT.app` to Applications; it is not notarized, so the first time open it with right click → Open |
| macOS 12 or later, Intel | `RMT-macOS-x86_64.dmg` | as above; also runs on Apple Silicon through Rosetta 2 |

Everything the program needs is inside each package.

## What changed

- **Sharp rendering**: Qt6 scales the window by the fractional DPI of the desktop (for example 1.1 with `Xft.dpi` 106, or 125% and 150% on Windows), which resampled the pixel-exact bitmaps of the tracker and made them blurry compared with Qt5. The scale factor is now rounded to a whole number, so the tracker is drawn 1:1 as in 2.0. Checked on Linux with X11, where the pattern grid is identical to the Qt5 one; not tried on Windows and macOS.
- **Sources**: reformatted in K&R style, enforced by `clang-format` and checked by `clang-tidy`; `PokeyRenderer`, `ConfigDlg` and `TuningDlg` renamed. No change in behaviour.
- **Docs**: `BUILD.md` explains how to use `clang-format` and `clang-tidy`.
